# 📚 ترنم مهر — شناساگر سال و درس سوالات کنکور (RAG)

این یک **Space استاتیک هوشمند** است که با موتور **RAG (Retrieval Augmented Generation)** سمت کلاینت، سال، درس و رشته‌ی سوالات کنکور را شناسایی می‌کند.

## ✨ ویژگی‌ها
- 🔍 جست‌وجوی هوشمند فارسی (نرمال‌سازی + bigram + تطبیق توکنی)
- 📅 شناسایی **سال کنکور** (۱۴۰۰ تا ۱۴۰۴)
- 📚 شناسایی **درس** (زیست، شیمی، فیزیک، حسابان، ادبیات، ...)
- 🎯 نمایش گزینه‌ی صحیح + توضیح + درصد تطبیق
- ⚡ کاملاً سمت کلاینت (بدون سرور، رایگان، سریع)

## 🗂️ ساختار
```
├── index.html       ← رابط کاربری
├── app.js           ← موتور RAG
├── styles.css       ← استایل
└── data/exams.json  ← پایگاه دانش سوالات (قابل گسترش)
```

## 🔧 گسترش پایگاه دانش
از نوت‌بوک Colab (`notebooks/rag_exam_colab.ipynb`) برای افزودن سوال جدید و ساخت مدل TF-IDF استفاده کنید، سپس فایل `data/exams.json` را آپدیت کنید.

## 🔗 اتصال به سایت اصلی
این Space به سایت اصلی ترنم مهر متصل است و می‌تواند برای غنی‌سازی پاسخ‌های هوش مصنوعی استفاده شود.
